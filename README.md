## How versioning works

- Each document carries a semantic version and an effective date in its header.
- Every change is recorded in [CHANGELOG.md](CHANGELOG.md) and in this repo's git history.
- When a user accepts the Terms in the LotJitsu app (at signup or before export), the app records the version and a timestamp of the acceptance. This repo is the public reference for what each version said.
- The marketing site (lotjitsu.com/terms and lotjitsu.com/privacy) renders the current version of these documents and links here for history.
